# Kookee Unified Backend - API Specification
**Version**: 1.0.0
**Base URL**: `/api/v1`

## 1. Authentication & Security
**Strategy**: JWT (Access Token + Refresh Token).
**Headers**: `Authorization: Bearer <token>`

### 1.1 Login (Exchange Credentials)
- **POST** `/auth/login`
- **Body**: `{ "username": "...", "password": "..." }`
- **Response**: `200 OK`
  ```json
  {
    "accessToken": "ey...",
    "refreshToken": "ref...",
    "expiresIn": 3600,
    "user": { "id": "uuid", "role": "MERCHANDISER|ADMIN", "fullName": "..." }
  }
  ```

### 1.2 Refresh Token
- **POST** `/auth/refresh`
- **Body**: `{ "refreshToken": "..." }`
- **Response**: `200 OK` (New Access Token)

### 1.3 Logout / Revocation
- **POST** `/auth/logout`
- **Body**: `{ "refreshToken": "..." }`
- **Effect**: Invalidates the refresh token session in the DB.

## 2. Assignments
### 2.1 Get Assignments (My Schedule)
- **GET** `/assignments`
- **Query Params**: `date=YYYY-MM-DD` (Optional)
- **Access**:
    - `MERCHANDISER`: Returns ONLY their assignments.
    - `ADMIN`: Returns ALL assignments (can filter by `merchandiserId`).
- **Response**:
  ```json
  [
    {
      "id": "uuid",
      "outlet": { "id": "uuid", "name": "Lugogo Mall", "location": { "lat": 0.0, "lng": 0.0 } },
      "date": "2026-01-18",
      "instructions": "Check freezer stock",
      "status": "PENDING"
    }
  ]
  ```

### 2.2 Create Assignment (Admin Only)
- **POST** `/assignments`
- **Body**: `{ "merchandiserId": "uuid", "outletId": "uuid", "date": "YYYY-MM-DD", "instructions": "..." }`
- **Response**: `201 Created`

---

## 3. Visits & Tracking
### 3.1 Start Visit
- **POST** `/visits/start`
- **Body**:
  ```json
  {
    "outletId": "uuid",
    "location": { "lat": 0.3476, "lng": 32.5825 }
  }
  ```
- **Response**: `200 OK` `{ "visitId": "uuid" }`

### 3.2 End Visit
- **POST** `/visits/{visitId}/end`
- **Body**: `{ "location": { "lat": ..., "lng": ... } }`
- **Response**: `200 OK`

---

## 4. Reports & OCR Pipeline
### 4.1 Submit Report (Async)
- **POST** `/reports`
- **Content-Type**: `multipart/form-data`
- **Parts**:
    - `file`: (Binary Image)
    - `data`: (JSON) `{ "visitId": "uuid", "clientTimestamp": "ISO8601" }`
- **Idempotency**: Use `Idempotency-Key` header (UUID generated by client).
- **Behavior**:
    1. Uploads image to storage.
    2. Creates `Report` record with status `PENDING_REVIEW`.
    3. Triggers Async OCR Job.
- **Response**: `202 Accepted` `{ "reportId": "uuid", "status": "PENDING_REVIEW" }`

### 4.2 Get Report Details
- **GET** `/reports/{id}`
- **Access**: Merchandiser (Own only), Admin (Any).
- **Response**:
  ```json
  {
    "id": "uuid",
    "status": "AUTO_APPROVED",
    "imageUrl": "https://...",
    "items": [
      {
        "sku": "ITEM-001",
        "label": "Perfect Slices 100g",
        "quantity": 5,
        "confidence": 0.95,
        "flags": []
      },
      {
        "sku": "ITEM-002",
        "label": "Unknown Item",
        "quantity": 3,
        "confidence": 0.4,
        "flags": ["LOW_CONFIDENCE"]
      }
    ]
  }
  ```

### 4.3 Update Report Items (Correction/Override)
- **PUT** `/reports/{id}/items`
- **Access**:
    - `MERCHANDISER`: Only if status is `PENDING_REVIEW` or `FLAGGED` (correction flow).
    - `ADMIN`: Any time (Override).
- **Body**:
  ```json
  {
    "items": [
      { "productId": "uuid", "quantity": 10, "isManualOverride": true }
    ]
  }
  ```
- **Audit**: Logs the `old_value` and `new_value`.
